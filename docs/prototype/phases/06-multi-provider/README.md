# Phase 6 — Multi-provider Expansion

**State:** Planned; depends on Phase 4.

## Outcome

Additional GPU marketplaces can be selected through the same API with no
algorithm changes.

## Required deliverables

- [ ] Vast.ai connector.
- [ ] Lambda Cloud connector.
- [ ] CoreWeave connector.
- [ ] Provider-specific tier, storage, credentials, lifecycle, and pricing mappings.
- [ ] Conformance evidence for every registered connector.
- [ ] Provider matrix and setup guide updates.

## Exit gate

At least two additional providers pass the packaged conformance suite and run
the canonical K-Means acceptance job through the unchanged public API.
